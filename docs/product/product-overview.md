# ContextRelay Product Overview

**The Person Can Leave. The Client Context Should Not.**

ContextRelay is an institutional memory and client continuity platform built specifically for professional service agencies, consultancies, and account teams. It eliminates agency-client knowledge loss when account managers depart by retaining every client decision, preference, constraint, and rejection in durable long-term memory.

---

## 1. The Core Problem: The Brain Drain at Handover

In digital agencies and consultancies, the most valuable asset is not the code repository or design Figma file — it is the **nuanced institutional context** stored inside the account manager's head.

Over 12 to 24 months on an account, an Account Manager learns:
- Which design aesthetics the client CEO despises.
- Which architectural decisions were tried, failed, and abandoned.
- Who holds the real veto power versus who holds nominal titles.
- Why specific technologies were chosen over alternatives.
- How client preferences evolved over time.

When that account manager resigns, this context walks out the door. The incoming account manager inherits a calendar, an empty CRM thread, and scattered Google Docs. Inevitably, the new manager:
1. Re-proposes concepts the client already rejected six months ago.
2. Inquires about requirements the client already explained three times.
3. Violates unwritten communication norms.
4. Erodes client trust and damages account retention.

---

## 2. The Solution: Institutional Memory for Client Continuity

ContextRelay acts as a permanent, client-isolated memory relay. Instead of letting conversational knowledge evaporate into raw transcript archives, ContextRelay extracts durable facts, decisions, and preferences, anchoring them into long-term memory.

When Account Manager B takes over the account, they do not start from scratch. They can:
- Query historical client decisions and receive grounded, citation-backed answers.
- Review verifiable source quotes and meeting timestamps.
- Generate an authoritative **Account Handover Dossier** covering current technical decisions, key stakeholders, rejected approaches, and communication preferences.

---

## 3. Who It Is For

- **Digital & Software Agencies:** Technical consultancies managing custom web, cloud, and mobile development projects.
- **Brand & Marketing Agencies:** Creative firms where aesthetic preferences, brand taboos, and campaign histories are critical.
- **Enterprise Customer Success Teams:** Technical account managers (TAMs) handling high-touch enterprise accounts with complex stakeholder hierarchies.

---

## 4. Key Capabilities

1. **Client-Isolated Memory Banks:** Each agency client is allocated a discrete, isolated Hindsight memory bank. Information from Client A can never be retrieved in inquiries regarding Client B.
2. **Durable Fact Extraction:** Parses conversational meeting transcripts and documents into queryable entity memories, preserving temporal context and decision changes over time.
3. **Strict Evidence Grounding:** Answers are synthesized exclusively from recalled memory facts. When no record exists, the system explicitly states that no memory was found, eliminating AI hallucinations.
4. **Verifiable Audit Trail:** Every answer expands to reveal the underlying source facts, meeting dates, and confidence scores.
5. **One-Click Handover Dossier:** Aggregates multi-faceted memory recalls into an executive briefing document tailored for incoming personnel.
